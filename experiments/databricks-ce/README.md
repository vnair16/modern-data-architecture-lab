# Databricks Community Edition Experiments

Use this folder for exported notebooks, run notes, and screenshots from Databricks Community Edition.

## Community Edition Notes

Databricks Community Edition is useful for Spark, PySpark, SQL, Delta-style exercises, execution plans, and notebook-based demonstrations. Some enterprise features may be unavailable or limited, especially production governance, Unity Catalog, account-level administration, jobs, service principals, private networking, and full Lakeflow workflows.

When a topic depends on an enterprise feature, create one of these artifacts:

- A design note explaining the intended production setup.
- A mock implementation using local files, schemas, or configuration.
- A diagram showing how the feature would be used in a paid workspace.
- A README that clearly labels what was tested directly and what was simulated.
