# Spark Databricks Notebooks

These files are Databricks source-format notebooks. Import them into Databricks Community Edition or copy cells into a Databricks notebook.

Recommended order:

1. `01_spark_architecture_and_execution.py`
2. `02_spark_sql_files_and_tables.py`
3. `03_dataframe_api_practical.py`
4. `04_query_planning_and_optimization.py`
5. `05_structured_streaming_basics.py`

Each notebook creates its own sample data and includes markdown notes around the practical examples so you can add more cells as you learn.
